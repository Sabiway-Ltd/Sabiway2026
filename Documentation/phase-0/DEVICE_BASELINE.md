# Phase 0 device and responsiveness baseline

Phase 0 changes repository controls and configuration, not user-interface layouts. Therefore no visual regression is introduced by this phase. The following matrix is mandatory from Phase 1 onward.

| Surface | Required widths/devices | Phase 0 status |
|---|---|---|
| Web mobile | 320, 360, 375, 390, 412 px | Baseline pending |
| Web tablet | 768, 820, 1024 px | Baseline pending |
| Web desktop | 1280, 1440, 1920 px | Baseline pending |
| Mobile app | Current supported small/standard/large iPhone and Android profiles | No mobile code exists |
| Accessibility | Keyboard, visible focus, 200% zoom, reduced motion, screen-reader landmarks | Baseline pending |
| Browsers | Current stable Chrome, Safari, Firefox and Edge | Baseline pending |

Every later phase must attach screenshots or automated evidence for affected breakpoints and execute the relevant journey on at least one iOS, one Android and the affected web widths.
