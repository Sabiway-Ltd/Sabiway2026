# Phase 0 open decisions and owners

| Decision | Recommendation | Owner |
|---|---|---|
| Mobile framework | React Native with Expo | Product/technical owner |
| Main-branch protection | Require pull request, one approval, conversation resolution and passing Phase 0 CI | Organization owner |
| Additional administrator | Add one trusted backup organization owner/admin; grant developers through teams | Organization owner |
| Credential rotation | Rotate all copied credentials before any deployment | Organization owner |
| Realtime service authentication | Use a dedicated backend-to-realtime token or signed request scheme | Technical owner |
| Staging ownership | Create separate staging credentials/data and name the release approver | Product/technical owner |
